# Coati Space Project — React + Node.js

Перенос приложения из `Nosuha-Space` на подготовленный шаблон без новых npm-зависимостей.
Проверено на Node.js **26.13.0**; используется встроенный `node:sqlite`.
Папки приложения находятся внутри `Coati Space Project`, медиа — в корневой `Resource`.

## Единый запуск

Команды PowerShell **из корня репозитория**; зависимости шаблона уже установлены:

```powershell
Set-Location 'Coati Space Project/Client'
npm run build
Set-Location ../Server
npm start
```

Открыть [главную зоопарка](http://localhost:3000/stav-zoo)
или [карточку носухи](http://localhost:3000/stav-zoo/coati).
Node.js раздаёт готовую сборку `Client/dist`, API и медиа; отдельный Vite-сервер
для этого запуска не нужен. Прямое открытие и обновление обоих адресов работают.
Остановка сервера — `Ctrl+C`.

Если зависимости отсутствуют после клонирования, перед сборкой выполнить
`npm ci` отдельно в `Coati Space Project/Client` и `Coati Space Project/Server`.
Используются существующие `package.json` и lock-файлы.

После входа открывается `/diary`; доступны создание, редактирование,
подтверждение удаления и исходные фильтры. Дата «до» включается целиком,
новые записи идут первыми, список сотрудников берётся из всех записей.
Как в оригинале, «Уборка» есть в формах, но отсутствует среди кнопок фильтра.
Cookie авторизации действует 8 часов; выход возвращает на карточку носухи.

При первом запуске создаётся `Coati Space Project/Server/coati.db`
с исходными таблицами и начальными данными. Повторный запуск сохраняет изменения
и не восстанавливает удалённые записи. Ключ cookie — `Server/.auth-key`.
База, ключ и собранный `Client/dist` исключены из Git.

Фотографии доступны по `/images/...`, видео — по `/videos/...` из `Resource`.
В камере, как в оригинале, воспроизводится одно локальное видео с постером,
без звука и с повтором. `POST /Zoo/Donate` перенаправляет на исходную страницу
CloudTips; сам редирект не создаёт платёж или запись пожертвования в БД.

## Проверки

Из корня репозитория:

```powershell
Set-Location 'Coati Space Project/Client'
npm run build
Set-Location ../Server
npm test
```

12 тестов проверяют БД, авторизацию, CRUD, фильтры, границы дат, сообщения ошибок,
разбор многострочных заметок, раздачу сборки, всех медиа и видео по диапазонам байт.
Тесты требуют предварительной сборки клиента; изменения дневника в тестах
выполняются в изолированных БД. Ожидаемые ошибки отрицательных сценариев
выводятся в журнал сервера, а результат тестов — в итоговом счётчике.

При финальной сверке с запущенным оригиналом совпали тексты публичных страниц,
размеры основных блоков, пять текстовых API, 18 сочетаний фильтров и списки
сотрудников; все 12 медиафайлов совпали побайтово.
Согласованное отличие маршрутизации: `/stav-zoo` открывает готовую главную
зоопарка, а возврат с карточки ведёт на этот локальный адрес.
Ошибки возвращают явные HTTP-статусы и отображаются пользователю.

## Разработка

Сначала выполнить сборку выше, затем открыть два терминала из корня репозитория:

```powershell
# Терминал 1
Set-Location 'Coati Space Project/Server'
npm run dev
```

```powershell
# Терминал 2
Set-Location 'Coati Space Project/Client'
npm run dev
```

Открыть адрес Vite из второго терминала с путём `/stav-zoo` (обычно
`http://localhost:5173/stav-zoo`). Запросы к API, вход, дневник, донат и медиа
передаются серверу на `http://localhost:3000`.
Для смены порта Node.js задать `$env:PORT = '3001'` перед его запуском;
в режиме разработки также заменить адрес сервера в `Client/vite.config.js`.

Текстовые API оригинала: `GET /api/coati`, `/api/coati/info`,
`/api/coati/diary`, `/api/coati/donations`, `/api/coati/status`.
Защищённое API дневника: `GET/POST /api/diary`,
`GET/PUT/DELETE /api/diary/:id`; параметры списка —
`filterType`, `dateFrom`, `dateTo`, `author`.
